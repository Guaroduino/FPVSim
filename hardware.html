Guía de Construcción Exacta: Consola Portátil ESP32-S3 N16R8 + IPS 2.8"

Documentación de ingeniería hardware 1 a 1 para armar la consola física capaz de correr el motor Voxel Comanche (Chorobobo 2048×1024 en PSRAM Octal) y el OSD estilo INAV a 60 FPS por DMA (320×240 RGB565).

MCU: ESP32-S3 N16R8 (240 MHz) PSRAM: 8 MB Octal OPI (80 MHz) Pantalla: 2.8" IPS ILI9341V (SPI2 60-80MHz DMA) Touch: FT6336U Capacitivo (I2C 400kHz) Sticks: 2x Analógicos 12-Bit (Exclusivo ADC1)

⚠️ REGLA DE ORO DEL MÓDULO N16R8 (PSRAM OCTAL)

En el ESP32-S3-WROOM-1-N16R8, los pines GPIO 33, 34, 35, 36 y 37 están conectados internamente al bus de 8 líneas de la memoria PSRAM Octal de 8 MB.

¡PROHIBIDO conectar cables o botones a GPIO 33–37! Si los usas, el chip colapsará al alojar los mapas Voxel (voxHeight y voxColor).

📐 2. Esquemas Eléctricos y Arquitectura de Buses

Diagramas exactos de la etapa de batería LiPo, bus de pantalla + touch, filtrado analógico de joysticks y partición de memoria.

🔋 A. Etapa de Batería LiPo 1S + Carga USB-C + Filtros de Ruido

Consejo clave: Alimenta los 2 joysticks desde el pin regulado 3V3 del ESP32-S3 (nunca desde 5V) y coloca un condensador cerámico de 100 nF (104) entre cada pin ADC (GPIO 1, 2, 4, 5) y GND.

🖥️ B. Conexión Pantalla 2.8" IPS (SPI2 60-80MHz) + Touch FT6336 (I2C)

Por qué GPIO 10, 11, 12 y 13: Son los pines nativos FSPI del silicio ESP32-S3. Evitan pasar por la matriz GPIO Matrix y logran 60–80 MHz estables sin artefactos en pantalla.

🕹️ C. Joysticks Analógicos Modo 2 (ADC1) + Cruceta y Diamante

Cero resistencias externas en botones: Los 12 pulsadores usan INPUT_PULLUP interno del ESP32-S3; solo sueldas un pin del botón al GPIO y el otro a la pista común de GND.

🧠 D. Mapa de Memoria en Tiempo Real (SRAM Interna vs PSRAM Octal)

Paridad exacta: El raycaster escribe horizontalmente en voxBuf (SRAM interna) y luego des-rota a vram565 mientras el controlador DMA envía el frame anterior por SPI.

📄 include/fpvsim_hal.h — Pinout Oficial + Inicialización DMA SRAM / PSRAM Octal 
#pragma once
#include <Arduino.h>
#include <esp_heap_caps.h>
#define LGFX_USE_V1
#include <LovyanGFX.hpp>

// ============================================================================
// 1. MAPA DE PINES OFICIAL: RETRO-GO FPVSim (ESP32-S3 N16R8)
// ¡PROHIBIDO USAR GPIO 33..37 (Reservados Bus PSRAM Octal 8MB)!
// ============================================================================

// Pantalla IPS 2.8" ILI9341V (Bus SPI2 Nativo IOMUX @ 60-80 MHz DMA)
#define PIN_TFT_MOSI    11
#define PIN_TFT_MISO    13
#define PIN_TFT_SCLK    12
#define PIN_TFT_CS      10
#define PIN_TFT_DC       9
#define PIN_TFT_RST     14
#define PIN_TFT_BL      21

// Panel Touch Capacitivo FT6336U (I2C @ 400 kHz)
#define PIN_TOUCH_SDA    8
#define PIN_TOUCH_SCL   18
#define PIN_TOUCH_INT   17
#define PIN_TOUCH_RST   14  // Compartido con PIN_TFT_RST

// Joysticks Analógicos Duales Modo 2 (100% en ADC1 de 12 bits)
#define PIN_ADC_LX       1  // ADC1_CH0 -> Yaw
#define PIN_ADC_LY       2  // ADC1_CH1 -> Throttle
#define PIN_ADC_RX       4  // ADC1_CH3 -> Roll
#define PIN_ADC_RY       5  // ADC1_CH4 -> Pitch
#define PIN_BTN_L3       6  // Click Stick Izquierdo (INPUT_PULLUP)
#define PIN_BTN_R3       7  // Click Stick Derecho   (INPUT_PULLUP)

// Cruceta D-Pad + Sistema + Diamante de Acción (INPUT_PULLUP -> GND)
#define PIN_BTN_UP      15
#define PIN_BTN_DOWN    38
#define PIN_BTN_LEFT    39
#define PIN_BTN_RIGHT   40
#define PIN_BTN_SELECT  41
#define PIN_BTN_MENU    42
#define PIN_BTN_A       48  // Derecha (GAS / OK)
#define PIN_BTN_B       47  // Abajo   (BRK / BACK)
#define PIN_BTN_X       16  // Arriba  (RST)
#define PIN_BTN_Y        3  // Izq.    (MOD: ACRO/HOR/MANU)

// ============================================================================
// 2. DRIVER LOVYANGFX CON DMA PARA ILI9341V + FT6336
// ============================================================================
class LGFX_RetroGo : public lgfx::LGFX_Device {
  lgfx::Panel_ILI9341 _panel;
  lgfx::Bus_SPI       _bus;
  lgfx::Light_PWM     _light;
  lgfx::Touch_FT5x06  _touch;

public:
  LGFX_RetroGo(void) {
    {
      auto cfg = _bus.config();
      cfg.spi_host    = SPI2_HOST;
      cfg.spi_mode    = 0;
      cfg.freq_write  = 60000000; // 60 MHz DMA (subible a 80000000)
      cfg.freq_read   = 16000000;
      cfg.dma_channel = SPI_DMA_CH_AUTO;
      cfg.pin_sclk    = PIN_TFT_SCLK;
      cfg.pin_mosi    = PIN_TFT_MOSI;
      cfg.pin_miso    = PIN_TFT_MISO;
      cfg.pin_dc      = PIN_TFT_DC;
      _bus.config(cfg);
      _panel.setBus(&_bus);
    }
    {
      auto cfg = _panel.config();
      cfg.pin_cs          = PIN_TFT_CS;
      cfg.pin_rst         = PIN_TFT_RST;
      cfg.panel_width     = 240;
      cfg.panel_height    = 320;
      cfg.offset_rotation = 1;    // 320x240 Horizontal
      cfg.invert          = true; // IPS activo
      _panel.config(cfg);
    }
    {
      auto cfg = _light.config();
      cfg.pin_bl      = PIN_TFT_BL;
      cfg.freq        = 12000;
      cfg.pwm_channel = 7;
      _light.config(cfg);
      _panel.setLight(&_light);
    }
    {
      auto cfg = _touch.config();
      cfg.x_min           = 0;
      cfg.x_max           = 239;
      cfg.y_min           = 0;
      cfg.y_max           = 319;
      cfg.pin_int         = PIN_TOUCH_INT;
      cfg.pin_rst         = PIN_TOUCH_RST;
      cfg.offset_rotation = 1;
      cfg.i2c_port        = 0;
      cfg.i2c_addr        = 0x38;
      cfg.pin_sda         = PIN_TOUCH_SDA;
      cfg.pin_scl         = PIN_TOUCH_SCL;
      cfg.freq            = 400000;
      _touch.config(cfg);
      _panel.setTouch(&_touch);
    }
    setPanel(&_panel);
  }
};

// ============================================================================
// 3. RESERVA DE BUFFERS (SRAM INTERNA DMA vs PSRAM OCTAL)
// ============================================================================
static uint16_t* vram565   = nullptr; // 150 KB en SRAM Interna (DMA)
static uint16_t* voxBuf    = nullptr; // 128 KB en SRAM Interna (Raycaster)
static uint8_t*  voxHeight = nullptr; // 2.0 MB en PSRAM Octal
static uint16_t* voxColor  = nullptr; // 4.0 MB en PSRAM Octal
static uint16_t* voxSkyMap = nullptr; // 0.5 MB en PSRAM Octal

inline bool halInitConsole() {
  vram565   = (uint16_t*)heap_caps_malloc(320 * 240 * 2, MALLOC_CAP_INTERNAL | MALLOC_CAP_DMA);
  voxBuf    = (uint16_t*)heap_caps_malloc(256 * 256 * 2, MALLOC_CAP_INTERNAL | MALLOC_CAP_8BIT);
  voxHeight = (uint8_t*) heap_caps_malloc(2048 * 1024,   MALLOC_CAP_SPIRAM);
  voxColor  = (uint16_t*)heap_caps_malloc(2048 * 1024 * 2, MALLOC_CAP_SPIRAM);
  voxSkyMap = (uint16_t*)heap_caps_malloc(512 * 512 * 2,   MALLOC_CAP_SPIRAM);

  analogReadResolution(12);
  analogSetPinAttenuation(PIN_ADC_LX, ADC_11db);
  analogSetPinAttenuation(PIN_ADC_LY, ADC_11db);
  analogSetPinAttenuation(PIN_ADC_RX, ADC_11db);
  analogSetPinAttenuation(PIN_ADC_RY, ADC_11db);

  const int btns[12] = {
    PIN_BTN_UP, PIN_BTN_DOWN, PIN_BTN_LEFT, PIN_BTN_RIGHT,
    PIN_BTN_SELECT, PIN_BTN_MENU, PIN_BTN_A, PIN_BTN_B,
    PIN_BTN_X, PIN_BTN_Y, PIN_BTN_L3, PIN_BTN_R3
  };
  for (int p : btns) pinMode(p, INPUT_PULLUP);

  return (vram565 && voxBuf && voxHeight && voxColor && voxSkyMap);
}
