Copia aquí los mapas exportados desde el simulador web (botón "⬇ MAPA"), por ejemplo
chorobobo_hd.fpvm o rccar.fpvm, y súbelos a la consola con:

    pio run -t uploadfs

Cada mapa ocupa 4.0 MB; la partición LittleFS (~12.4 MB) admite 2 mapas con margen.
En la consola, MENU pasa al siguiente mapa (y al final, al mapa procedural integrado).
